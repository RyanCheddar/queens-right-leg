Card 3D-ifier

Card 3D-ifier allows you to add special effects to supported cards, giving them some extra bling!

{% hint style="info" %} Card 3D-ifier does not and cannot modify how your card looks in Karuta. It is a feature that is purely just for fun. {% endhint %}

{% hint style="info" %} Command: "leg 3dify"\ Aliases: "3d"

\ Card 3D-ifier requires you to reply to a "Card Details" message in order for it to work. {% endhint %}

{% hint style="info" %} A list of supported character editions is available [here] {% endhint %}

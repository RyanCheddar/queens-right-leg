# Affection Calculator

!!! info  
    Command: "leg affcalc"  

    Requires replying to a visit menu.  

Affection Calculator allows you to see your Affection Rating as a raw value, as well as see where it would end up when halved (as a result of someone else becoming Koibito).  

As Karuta's affection rating formula is not public, the calculator only provides a rough estimate. This estimate may get more inaccurate as your Affection Rating gets higher, as a result of both inaccuracies in the estimation formula and loss of information from rounding.
